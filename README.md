# BUP (Business Up) — Virtual Data Room

Une data room (ou salle de données virtuelle — VDR, Virtual Data Room) est un espace numérique sécurisé dans lequel une entreprise centralise des documents confidentiels afin de les partager avec des personnes autorisées : investisseurs, banques, partenaires, auditeurs, avocats, acquéreurs, etc.

À quoi sert une data room ?

Elle est particulièrement utilisée lors de :

levées de fonds → investisseurs et VC examinent l'entreprise avant d'investir ;

due diligence → vérification juridique, financière, commerciale et technique ;

acquisition / cession d'entreprise → l'acquéreur analyse la société ;

demande de financement bancaire ;

partenariats stratégiques ;

subventions ou programmes d'investissement. je voudrais une plateforme qui permet d'assurer la gestion de data room
